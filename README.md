# 會員網店初形（members-shop）

- **GitHub repo 名（必須用新 repo）**：`members-shop`
- **建議 Pages 網址**：https://ittonywong.github.io/members-shop/
- **重要**：同現有會員站 https://ittonywong.github.io/members/ **分開**。請開新 repo `members-shop`，**唔好**覆蓋舊 `members`。
- **DEMO_MODE = true**：示範產品＋localStorage；付款掣「即將開放」停用；**唔會真收款**；冇卡號／CVV 欄；冇 Stripe key
- **試睇帳戶**：`demo@demo.local`（會員）、`admin@demo.local`（CMS）；密碼任意 ≥ 8 位
- **Base path**：自動偵測 `/members-shop/`。若改 repo 名，要改每個 HTML 入面嘅 `REPO="members-shop"`。
- **部署**：總經理自己 Upload 並開 Pages；團隊無 GitHub 權限

詳見 `上載說明-會員網店-members-shop.docx`。
